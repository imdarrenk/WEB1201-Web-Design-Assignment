# WebWizards — WEB1201 Web Fundamentals Group Assignment

**Course:** WEB1201 Web Fundamentals  
**Group:** 12 

---

## About the Project

WebWizards is a fictional web design agency website built as the group assignment for WEB1201. The site presents a professional multi-page experience for a company that offers web design services, including a portfolio showcase, tiered pricing plans, a contact form, and a login/signup system.

The site is built entirely with vanilla HTML, CSS, and JavaScript. No frameworks or libraries used for this project.

---

## Features

- Responsive navbar with hamburger menu for mobile
- Multi-page navigation between public and authenticated views
- Client-side login validation redirecting to logged-in page variants
- Contact form with JavaScript validation
- Pricing tiers (Basic / Pro / Enterprise)
- Portfolio section with project showcases
